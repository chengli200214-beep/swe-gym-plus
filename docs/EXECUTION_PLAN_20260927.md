## 非连续重复命令防护（2026-09-27 接续）

- 失败日志表明旧防环只拦连续重复；三题中同一命令被其他动作隔开后仍会重复执行。已增加
  `SHA256(command + pre-action workspace digest)` 指纹：首次重复不调用工具、不给工具预算记账，
  记录 `executed=false` 的事件，并向模型保留该签名对应的真实历史回执与单独的 Harness 提醒；
  提醒后再次请求相同动作则终止。工作区版本变化后允许同一命令重新执行。
- 重启/恢复时从 append-only 事件与动作日志重建历史，不依赖新增 checkpoint 字段；上下文压缩保留
  前一条真实动作/回执、被拒绝动作、协议结果和提醒。决策记录见 ADR 0011。
- 本机定向回归通过；全量回归最终为 **277 项通过、0 失败、0 错误、12 项平台条件跳过**。
  首次全量发现两条旧上下文探针仍匹配旧提醒措辞，已更新为验证新协议；修正后全量通过。
- 精确同步后的 AutoDL Linux 全量回归为 **277/277 通过、0 失败、0 跳过**；第一次云端调用因
  shell `PATH` 未包含 `agent-env/bin` 而找不到 `python`，原始失败报告保留，未作为产品回归结论。
- 同一冻结三题、同一 Qwen2.5-Coder-7B Base 和预算完成新一轮 NsJail 探针，结果仍为 **0/3**：
  5164/6535 均只有读取动作；5255 有一次 edit 尝试，但因 before 文本非唯一被拒绝；三题都在
  提醒后再次请求被拦截动作，未生成非空补丁。逐题统计和私有产物路径见
  [AutoDL 防重复探针报告](docs/AUTODL_REPEAT_GUARD_PROBE_20260927.md)。
