## Decision and remaining causal work

The current blocker is now mostly **patch correctness and testing/repair
behavior**, not only the ability to emit an edit. Repeated error text alone
did not fix invalid tool selection. The existing plan's prerequisite of at
least one independently passing autonomous dev patch is still unmet. Do
not train on the 250 old shell-only actions or claim model improvement.

The next model experiment needs one distinct, measurable hypothesis:
whether a real *visible*, non-sealed post-edit test receipt and a bounded
chance to revise the patch produce a correct candidate. Keep the same
frozen task IDs and independent evaluator. Any harness-driven test must be
recorded as harness assistance, not as a model action, and must not expose
hidden evaluator selectors or gold patches. In parallel, finish the
independent service/frontend and reproducibility acceptance work.
