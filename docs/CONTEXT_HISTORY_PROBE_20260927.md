## 修改与目的

## 已确认的失败机制线索

6212 的 recent-history-v3 第 5 次模型输入包含有效重复提醒及四轮历史，
但下一动作仍为同一段超长 Python here-document 读文件命令。
该次输出达到 768 token 上限，现有解析器标记为
`parsed truncated JSON command` 后仍交给 shell 执行；工具返回 exit code 2，
stderr 包含 here-document 结束符不匹配及 shell 语法错误。

因此，提醒未送达这一工程缺陷已经修正，但它不足以解决实际模型的重复行为。
至少该实例同时涉及超长动作生成、截断后的命令恢复及无效动作执行。
这不是所有失败的唯一根因证明。本轮保持解析器与输出预算不变，避免混入第二个变量；
后续应先验证不完整动作拒绝/纠正机制及训练动作质量，而非直接增加训练轮数。
