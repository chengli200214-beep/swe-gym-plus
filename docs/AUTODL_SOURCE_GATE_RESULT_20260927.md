## 根据失败观察进行的通用改动

- 精简共享系统指引，先根据实际文件/包信息判断仓库语言；题面可能包含其他语言的客户端示例。
- 搜索必须带行号，再读取命中附近；不从大文件第一行顺序翻页寻找函数。
- 明确测试用于理解期望，修复对象是实现，不是修改测试答案。
- 明确 before 从 read 的解码 text 字段精确复制，保留空格与换行。
  已读取路径但文本不匹配时，给出具体空白说明；不自动修补或执行错误文本。
- 给 gate 运行新增独立 output-root。复测明确标记 development_retest，
  不覆盖首次负结果、不改变冻结 manifest、准入报告、预算或独立判分。

未向提示词加入任何 Moto 题目的具体路径、函数实现、gold patch 或答案。
这是同一开发集上的诊断调参；复测不再宣称是首次未曝光评测。
旧独立测试、源码版本/精确匹配、两次编辑拒绝和重复命令停止门槛保持不变。

## 源码展示边界修正

实际 read 包的 text 原先位于 stdout JSON 字符串中，再被 Tool result JSON 编码。
这个双层格式在日志中可直接观察到；复测亦有模型输出双重转义的 before/after。
这不证明它是全部失败的唯一原因，也不保证换格式会提高修复率。

新增共享展示转换：已验证的 typed read 将 text 精确解码为模型视图 stdout，
保留 source_read 路径、版本与范围，并标记 decoded-source-text-v1。
原始 journal/events 回执不修改；源码版本和匹配校验仍只使用原始真实证据。
任意 shell stdout 不会被转换成受信源码。运行、上下文压缩与 SFT 回放共享该转换。
后续复测仍使用相同开发题，不作为未曝光留出评测；详见 ADR 0008。
