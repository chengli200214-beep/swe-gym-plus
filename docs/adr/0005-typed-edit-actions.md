# ADR 0005 — 精确文本编辑进入自主 Agent

状态：实现中，真实模型开发任务门槛待验收。

## 原因与边界

现有 7B shell 轨迹在定位后仍因 sed/Python 引号错误无法写入。
诊断中的 path/before/after 曾真实写入，但语义错误，且控制器提供了文件定位，
不能替代正常自主流程。本决策只降低动作执行复杂度，不为模型提供任务答案。

模型动作协议新增 `edit`，包含相对 POSIX 路径、精确 before 和 after；
不得与 command 或 done=true 混合。沿用原 shell 动作作为探索与测试接口。
校验器拒绝绝对路径、父级跳转、Git 元数据、空 before、无变化和超长数据。
固定程序在现有隔离工具内读取文件，拒绝符号链接、多硬链接、非普通或超过 1 MiB 的文件；
必须匹配一次，Python 语法通过后原子写入。它不运行仓库导入，不在宿主执行模型代码。
只修改已经存在的 UTF-8 文件；新建文件不是本次已支持的功能。

## 可靠性与历史

编辑复用动作 intent/receipt/checkpoint，不另起一个恢复框架。
未知结果的副作用不重放。全任务最多一次格式纠正请求、最多两次被拒绝的编辑执行；
全部请求消耗同一预算，截断动作不执行。编辑失败是实际工具错误，不算成功修改。
近期历史保留 edit/receipt 与 protocol rejection，仍保留原题、有效重复提醒。
每次模型调用记录实际送入的上下文，转换器复用相同动作序列化与上下文策略。
不把 before 从第三方库 traceback 复制到仓库文件；原题和异常仍保留，不删去关键错误。

## 验收与回滚

合同测试覆盖路径、引用文本、语法拒绝、数据引号、重试上限、历史与 once-only 恢复；
云端另运行真实 NsJail 编辑测试。合同测试成功不等于模型独立修复成功。
随后冻结三题开发集、先做双控制、再自主运行与独立评测；0/3 停止扩大训练。
旧实验与旧 adapter 保留；通过 Git 提交可回退协议变更，不覆盖任何历史结果。
旧 last-action-v2 是仍在使用的实验对照，不作为新协议丢失反馈时的隐式 fallback。
