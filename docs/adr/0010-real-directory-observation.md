# ADR 0010：首次模型请求前提供真实、限额、可恢复的目录观察

状态：已实现；工程回归通过；同一开发集复测为 0/3；日期：2026-09-27。

## 证据与目标

三题开发复测仍为 0/3；其中持续猜测不存在的 services 路径，以及把题面中的测试
路径当作实现。单纯导航提示未解决问题。本变更只针对实际目录事实缺失，不声称
它是唯一根因，也不保证模型修改语义或测试成绩改善。

## 边界及数据流

- 固定 Python 程序在已选执行器内观察根文件名及二层子目录，不读取文件内容、
  gold/test patch 或 EvalSpec。每目录最多 512 项，包最多 3600 UTF-8 字节。
  不跟随目录 symlink；排除 .git、虚拟环境和常见依赖缓存；完整名字放不下则标记截断。
- 该操作属于框架而非模型，记录独立 harness_tool 事件与 intent/receipt，
  成功包进入最初 task JSON。目录名仍为不可信数据，不能充当 before/source-read 证据。
- 实际耗时与一次工具调用计入原预算，不新增免费模型动作或放宽上限。
  已确认回执恢复时不重跑、不重复计费；未知操作结果仍拒绝恢复。
- CLI 的新真实模型运行默认开启；可信脚本和直接 RunConfig 保持显式配置，
  gate 开启。存量 run.json 缺少该字段等价于声明默认 false，保留历史接续能力。
  原有预算、模型和任务仍严格匹配；这是持久化契约演进，不是双份执行路径。
- SFT 的最初 task 必须与真实 harness 回执一致，框架动作不是训练标签。
  老轨迹没有目录观察就保持没有，不从现有工作区给旧轨迹补造历史。

## 验证与回滚

验证真实路径、symlink/内容不读取、输出截断、原预算、取消、未知操作拒绝恢复、
已确认回执单次消费，以及 live/SFT 同一初始观察。三题复测保留相同冻结 manifest、
准入、总体工具/时间上限与独立判分；明确是开发复测，不是首次留出评测。
回滚按配置关闭观察，并恢复对应共享提示。保留原始事件，不删除负结果或历史配置。
至少一题非空自主补丁独立通过之前，不进入新训练或扩大数据采集。
